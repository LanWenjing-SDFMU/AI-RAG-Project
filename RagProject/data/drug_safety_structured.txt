药物名称：阿司匹林（Aspirin）
药物分类：非甾体抗炎药（NSAID）/ 抗血小板药
主要不良反应：
1. 胃肠道反应：恶心、呕吐、上腹不适、胃黏膜损伤、消化性溃疡、胃出血
2. 出血风险：延长出血时间，增加手术出血风险，颅内出血（罕见但严重）
3. 过敏反应：荨麻疹、血管神经性水肿、哮喘（阿司匹林哮喘综合征）
4. 瑞氏综合征：儿童病毒感染时使用可能诱发，表现为急性脑病和肝脂肪变性
5. 肾损伤：长期大剂量使用可能导致肾功能损害
6. 耳鸣、听力下降：大剂量使用时可出现
用药禁忌：
1. 对阿司匹林或其他NSAID过敏者禁用
2. 活动性消化性溃疡或消化道出血者禁用
3. 血友病或血小板减少症患者禁用
4. 严重肝肾功能不全者禁用
5. 妊娠晚期（第3 trimester）禁用
6. 儿童病毒感染（如水痘、流感）期间禁用（瑞氏综合征风险）
7. 哮喘患者慎用（可能诱发阿司匹林哮喘）
8. 正在使用抗凝药（华法林、利伐沙班等）的患者需谨慎评估
特殊人群提醒：
1. 老年人：胃肠出血风险增加，建议使用肠溶片或与胃黏膜保护剂联用
2. 儿童：16岁以下儿童慎用，病毒感染期间禁用
3. 孕妇：妊娠早期慎用，妊娠晚期禁用
4. 肾功能不全者：需调整剂量或避免使用
5. 肝功能不全者：需谨慎评估

药物名称：布洛芬（Ibuprofen）
药物分类：非甾体抗炎药（NSAID）
主要不良反应：
1. 胃肠道反应：消化不良、胃痛、恶心、呕吐、胃溃疡、消化道出血（较阿司匹林轻）
2. 肾损伤：长期大剂量使用可能导致肾功能损害、间质性肾炎
3. 心血管风险：长期大剂量使用增加血栓事件风险（心肌梗死、卒中）
4. 过敏反应：皮疹、荨麻疹、支气管痉挛
5. 肝损伤：罕见，但大剂量长期使用可能引起肝功能异常
6. 神经系统：头痛、头晕、嗜睡
用药禁忌：
1. 对布洛芬或其他NSAID过敏者禁用
2. 活动性消化性溃疡或消化道出血者禁用
3. 严重心功能不全者禁用
4. 严重肝肾功能不全者禁用
5. 妊娠晚期禁用
6. 冠状动脉搭桥术（CABG）围手术期禁用
7. 哮喘患者慎用
8. 正在使用抗凝药的患者需谨慎
特殊人群提醒：
1. 老年人：胃肠和肾毒性风险增加，建议最低有效剂量、最短疗程
2. 儿童：可用于儿童退热（剂量按体重计算），但需避免脱水状态使用
3. 孕妇：妊娠早期和中期慎用，妊娠晚期禁用
4. 高血压患者：可能降低降压药效果
5. 脱水患者：增加肾损伤风险，使用前应纠正脱水

药物名称：对乙酰氨基酚（Paracetamol / Acetaminophen）
药物分类：解热镇痛药（非NSAID）
主要不良反应：
1. 肝毒性：过量使用（单次>10g或长期>4g/天）可导致严重肝损伤甚至肝衰竭
2. 过敏反应：罕见，皮疹、荨麻疹
3. 血液系统：极罕见血小板减少、粒细胞缺乏
4. 大剂量长期使用可能引起肾损害
用药禁忌：
1. 对乙酰氨基酚过敏者禁用
2. 严重肝功能不全者禁用
3. 酒精滥用者慎用（增加肝毒性风险）
4. 正在使用肝酶诱导剂（如卡马西平、苯妥英钠）的患者需谨慎
5. 营养不良或长期禁食者肝毒性风险增加
特殊人群提醒：
1. 老年人：无需调整常规剂量，但需注意肝肾功能
2. 儿童：按体重计算剂量（10-15mg/kg），24小时内不超过4次
3. 孕妇：妊娠各期均可使用，为孕期首选解热镇痛药
4. 肝功能不全者：需减少剂量或延长给药间隔
5. 酒精依赖者：肝毒性风险显著增加，建议避免使用或严格限制剂量

药物名称：阿莫西林（Amoxicillin）
药物分类：青霉素类抗生素
主要不良反应：
1. 过敏反应：皮疹、荨麻疹、瘙痒、血管神经性水肿，严重者可发生过敏性休克
2. 胃肠道反应：腹泻、恶心、呕吐、消化不良
3. 抗生素相关性腹泻：长期使用可导致艰难梭菌感染
4. 肝功能异常：罕见，可逆性肝酶升高
5. 血液系统：罕见白细胞减少、血小板减少
6. 中枢神经系统：大剂量使用可能引起抽搐（肾功能不全者风险增加）
用药禁忌：
1. 对青霉素类或头孢菌素类过敏者禁用
2. 传染性单核细胞增多症患者禁用（皮疹发生率显著增加）
3. 严重肾功能不全者需调整剂量
4. 苯丙酮尿症患者注意口服混悬液可能含有阿斯巴甜
特殊人群提醒：
1. 老年人：肾功能可能减退，需评估肾功能调整剂量
2. 儿童：按体重计算剂量，是儿童常用抗生素
3. 孕妇：妊娠期安全（FDA B类），可在医生指导下使用
4. 哺乳期：可少量进入乳汁，通常安全
5. 肾功能不全者：肌酐清除率<30ml/min需延长给药间隔

药物名称：头孢克肟（Cefixime）
药物分类：第三代头孢菌素类抗生素
主要不良反应：
1. 胃肠道反应：腹泻（最常见）、恶心、呕吐、腹痛
2. 过敏反应：皮疹、荨麻疹、药物热，与青霉素有部分交叉过敏
3. 肝功能异常：可逆性肝酶升高
4. 血液系统：罕见嗜酸性粒细胞增多、血小板减少
5. 肾功能影响：罕见间质性肾炎
6. 抗生素相关性腹泻：艰难梭菌感染风险
用药禁忌：
1. 对头孢菌素类或青霉素类严重过敏者禁用
2. 既往有头孢菌素相关严重不良反应史者禁用
3. 严重肾功能不全者需调整剂量
4. 有胃肠道疾病史（特别是结肠炎）者慎用
特殊人群提醒：
1. 老年人：肾功能减退者需调整剂量
2. 儿童：按体重计算剂量，6个月以下婴儿安全性未确定
3. 孕妇：妊娠期慎用（FDA B类）
4. 肾功能不全者：肌酐清除率<20ml/min需减量

药物名称：华法林（Warfarin）
药物分类：口服抗凝药（维生素K拮抗剂）
主要不良反应：
1. 出血风险：最常见且最严重，包括鼻出血、牙龈出血、皮肤瘀斑、消化道出血、颅内出血
2. 皮肤坏死：罕见但严重，治疗初期可能出现皮肤坏死
3. 钙化防御：长期使用罕见，表现为小动脉钙化和皮肤坏死
4. 骨质疏松：长期使用可能增加骨折风险
5. 紫趾综合征：罕见，胆固醇微栓塞引起
用药禁忌：
1. 活动性出血或出血倾向者禁用
2. 近期颅内出血、眼部手术或创伤者禁用
3. 严重肝功能不全者禁用
4. 妊娠期禁用（可通过胎盘，致胎儿出血和畸形）
5. 恶性高血压患者禁用
6. 痴呆、精神病或酗酒者慎用（依从性差）
7. 血小板减少症患者慎用
8. 正在使用抗血小板药（阿司匹林、氯吡格雷）需密切监测
特殊人群提醒：
1. 老年人：出血风险增加，需更频繁监测INR，使用较低维持剂量
2. 儿童：需经验丰富的专科医生指导，频繁监测INR
3. 孕妇：妊娠期禁用，可改用低分子肝素
4. 肝功能不全者：凝血因子合成减少，出血风险增加
5. 饮食影响：富含维生素K的食物（菠菜、西兰花、动物肝脏）需保持摄入稳定

药物名称：二甲双胍（Metformin）
药物分类：双胍类口服降糖药
主要不良反应：
1. 胃肠道反应：恶心、呕吐、腹泻、腹胀、食欲减退（最常见，通常为一过性）
2. 乳酸性酸中毒：罕见但严重（肾功能不全者风险增加）
3. 维生素B12缺乏：长期使用可能导致吸收减少
4. 金属味觉：部分患者出现
5. 肝功能异常：罕见
用药禁忌：
1. 严重肾功能不全（eGFR<30ml/min/1.73m²）禁用
2. 急性或慢性代谢性酸中毒（包括乳酸性酸中毒）禁用
3. 严重肝功能不全者禁用
4. 严重感染、脱水、休克等应激状态禁用（暂停使用）
5. 心力衰竭（急性或不稳定）患者禁用
6. 酒精滥用者禁用（增加乳酸性酸中毒风险）
7. 碘化造影剂检查前后需暂停使用（检查前48小时至检查后48小时）
特殊人群提醒：
1. 老年人：需定期评估肾功能（eGFR），eGFR<45时需减量
2. 儿童：10岁以上儿童可使用
3. 孕妇：妊娠期通常不推荐，胰岛素为金标准
4. 肾功能不全者：eGFR 30-45需减量，eGFR<30禁用
5. 肝功能不全者：谨慎使用

药物名称：氯吡格雷（Clopidogrel）
药物分类：抗血小板药（P2Y12受体抑制剂）
主要不良反应：
1. 出血风险：鼻出血、牙龈出血、皮肤瘀斑、消化道出血、颅内出血
2. 胃肠道反应：腹痛、消化不良、腹泻、便秘
3. 血栓性血小板减少性紫癜（TTP）：罕见但危及生命
4. 过敏反应：皮疹、瘙痒
5. 肝功能异常：罕见
6. CYP2C19慢代谢者：药效降低（基因多态性影响）
用药禁忌：
1. 活动性病理性出血（如消化性溃疡出血、颅内出血）禁用
2. 严重肝功能不全者禁用
3. 对氯吡格雷过敏者禁用
4. 正在使用抗凝药（华法林、利伐沙班等）需评估出血风险
5. 计划手术前5-7天应停药（除非紧急手术）
特殊人群提醒：
1. 老年人：出血风险增加，需评估获益与风险
2. 儿童：安全性未确定
3. 孕妇：妊娠期慎用（缺乏充分研究数据）
4. 肾功能不全者：轻中度无需调整剂量
5. CYP2C19慢代谢者：考虑换用替格瑞洛或普拉格雷

药物名称：硝苯地平（Nifedipine）
药物分类：钙通道阻滞剂（二氢吡啶类）/ 降压药
主要不良反应：
1. 血管扩张相关：面部潮红、头痛、头晕、踝部水肿
2. 心血管：心悸、心动过速、低血压（尤其短效制剂）
3. 胃肠道：恶心、呕吐、便秘、牙龈增生（长期使用）
4. 过敏反应：罕见皮疹、荨麻疹
5. 肝功能异常：罕见
6. 男性乳房发育：罕见
用药禁忌：
1. 心源性休克禁用
2. 严重主动脉瓣狭窄禁用
3. 不稳定型心绞痛（短效制剂可能增加风险）
4. 急性心肌梗死（起病4周内）慎用
5. 严重低血压（收缩压<90mmHg）禁用
6. 妊娠期慎用（可能抑制子宫收缩）
7. 与强效CYP3A4抑制剂（克拉霉素、伊曲康唑等）合用需谨慎
特殊人群提醒：
1. 老年人：起始剂量应减半，体位性低血压风险增加
2. 儿童：安全性未充分确定
3. 孕妇：妊娠期高血压可使用（但需医生评估）
4. 肝功能不全者：需减量
5. 糖尿病患者：对糖代谢无不良影响，可使用

药物名称：卡托普利（Captopril）
药物分类：血管紧张素转换酶抑制剂（ACEI）/ 降压药
主要不良反应：
1. 干咳：最常见（10-20%患者），无痰性刺激性咳嗽
2. 低血压：尤其首次剂量后（首剂低血压）
3. 高钾血症：尤其肾功能不全或合用保钾利尿剂时
4. 肾功能损害：双侧肾动脉狭窄患者可致急性肾损伤
5. 血管神经性水肿：罕见但严重（喉头水肿可致命）
6. 味觉异常：金属味或味觉减退
7. 皮疹：斑丘疹，常伴瘙痒
8. 中性粒细胞减少：罕见，肾功能不全者风险增加
用药禁忌：
1. 对ACEI过敏者禁用
2. 双侧肾动脉狭窄禁用
3. 妊娠期禁用（致胎儿肾发育异常和羊水过少）
4. 有血管神经性水肿史者禁用
5. 高钾血症（血钾>5.5mmol/L）禁用
6. 严重肾功能不全（eGFR<30）慎用
7. 与ARB（沙坦类）或直接肾素抑制剂合用需谨慎
特殊人群提醒：
1. 老年人：起始剂量应减半，监测肾功能和血钾
2. 儿童：可用于儿童高血压（剂量按体重计算）
3. 孕妇：妊娠期禁用（致畸风险），备孕女性也应避免
4. 肾功能不全者：需减量并监测血钾和肌酐
5. 糖尿病患者：保护肾脏，但需监测血钾

药物名称：阿托伐他汀（Atorvastatin）
药物分类：他汀类降脂药（HMG-CoA还原酶抑制剂）
主要不良反应：
1. 肌肉相关：肌痛、肌炎、横纹肌溶解（罕见但严重）
2. 肝功能异常：肝酶升高（ALT/AST），通常无症状
3. 胃肠道反应：便秘、腹胀、消化不良
4. 神经系统：头痛、头晕、失眠
5. 新发糖尿病风险：长期使用轻度增加
6. 过敏反应：皮疹、荨麻疹
用药禁忌：
1. 活动性肝病或不明原因肝酶持续升高禁用
2. 妊娠期和哺乳期禁用
3. 对阿托伐他汀过敏者禁用
4. 严重肾功能不全者需谨慎
5. 与强效CYP3A4抑制剂（环孢素、克拉霉素、伊曲康唑等）合用需调整剂量
6. 大量饮酒者慎用
特殊人群提醒：
1. 老年人：无需调整剂量，但需监测肌肉症状
2. 儿童：10岁以上可用于家族性高胆固醇血症
3. 孕妇：妊娠期禁用（影响胎儿胆固醇合成）
4. 肝功能不全者：活动性肝病禁用，需监测肝酶
5. 甲状腺功能减退者：需先治疗甲减，否则肌病风险增加

药物名称：左甲状腺素（Levothyroxine）
药物分类：甲状腺激素替代治疗药
主要不良反应：
1. 过量使用（甲亢症状）：心悸、心动过速、心律失常、焦虑、失眠、震颤、多汗、体重下降
2. 剂量不足：甲减症状持续（乏力、怕冷、便秘、体重增加）
3. 过敏反应：罕见皮疹
4. 长期过量：增加房颤风险和骨质疏松风险（尤其绝经后女性）
用药禁忌：
1. 未经治疗的肾上腺皮质功能不全禁用
2. 甲状腺毒症（甲亢）禁用
3. 急性心肌梗死期禁用
4. 与含铁、钙、铝制剂需间隔4小时服用
5. 与质子泵抑制剂、考来烯胺等药物需调整服药时间
特殊人群提醒：
1. 老年人：起始剂量应较低（12.5-25μg/天），缓慢加量
2. 儿童：按体重计算剂量，需频繁监测
3. 孕妇：妊娠期剂量通常增加30-50%，需密切监测TSH
4. 冠心病患者：起始剂量应极低，缓慢加量
5. 绝经后女性：避免长期过量使用（骨质疏松风险）

药物名称：地西泮（Diazepam / Valium）
药物分类：苯二氮卓类 / 抗焦虑药 / 镇静催眠药
主要不良反应：
1. 中枢神经系统抑制：嗜睡、头晕、乏力、共济失调、注意力不集中

药物名称：阿片类药物通用安全信息
药物分类：阿片类镇痛药
主要不良反应：
1. 呼吸抑制：所有阿片类药物的最危险不良反应，剂量依赖性
2. 便秘：几乎所有阿片类药物均引起，需预防性使用通便药
3. 耐受性和依赖性：长期使用不可避免，需监测
4. 恶心呕吐：初始使用时常见，通常3-5天后缓解
5. 镇静/嗜睡：初始使用或加量时常见
6. 瘙痒：组胺释放引起
7. 尿潴留：尤其老年男性
8. 免疫抑制：长期使用可能影响免疫功能
9. 内分泌影响：性腺功能减退、骨质疏松
用药禁忌：
1. 严重呼吸抑制禁用
2. 急性哮喘发作禁用
3. 麻痹性肠梗阻禁用
4. 颅脑损伤或颅内压增高禁用
5. 正在使用MAOI或停药14天内禁用
6. 妊娠期长期使用可致新生儿戒断综合征
特殊人群提醒：
1. 老年人：呼吸抑制和跌倒风险增加，起始剂量应减半
2. 儿童：需精确计算剂量
3. 孕妇：妊娠期长期使用可致新生儿戒断综合征
4. 肝功能不全者：需减量
5. 肾功能不全者：代谢产物蓄积，需减量
6. 所有患者：需监测呼吸频率、镇静程度和肠道功能

药物名称：青霉素类抗生素通用安全信息
药物分类：β-内酰胺类抗生素
主要不良反应：

1. 对青霉素类或头孢菌素类过敏者禁用

3. 严重肾功能不全者需调整剂量
4. 有青霉素相关严重过敏史者禁用所有β-内酰胺类
特殊人群提醒：
1. 老年人：肾功能减退者需调整剂量
2. 儿童：按体重计算剂量
3. 孕妇：妊娠期安全（FDA B类）
4. 肾功能不全者：需根据肌酐清除率调整剂量
5. 过敏史患者：使用前必须进行皮试

药物名称：头孢菌素类抗生素通用安全信息
药物分类：β-内酰胺类抗生素（头孢菌素类）

6. 双硫仑样反应：部分头孢（头孢哌酮、头孢曲松）与酒精合用
7. 抗生素相关性腹泻：艰难梭菌感染

用药禁忌：

3. 严重肾功能不全者需调整剂量
4. 使用含NMTT侧链头孢期间及停药后5天内禁止饮酒
特殊人群提醒：
1. 老年人：肾功能减退者需调整剂量
2. 儿童：按体重计算剂量
3. 孕妇：妊娠期安全（FDA B类）
4. 肾功能不全者：需根据肌酐清除率调整剂量
5. 维生素K缺乏者：使用含NMTT侧链头孢时需补充维生素K

药物名称：喹诺酮类抗生素通用安全信息
药物分类：喹诺酮类抗生素
主要不良反应：

7. 血糖紊乱：尤其糖尿病患者使用加替沙星（已撤市）
8. 关节软骨损伤：动物实验显示幼年动物关节软骨损伤
用药禁忌：
1. 对喹诺酮类过敏者禁用

3. 妊娠期和哺乳期禁用
4. 有肌腱疾病史者禁用
5. QT间期延长或正在使用延长QT间期药物者慎用
6. 癫痫患者慎用
7. 重症肌无力患者禁用（可能加重症状）

3. 孕妇：妊娠期禁用
4. 肾功能不全者：需调整剂量

药物分类：大环内酯类抗生素
主要不良反应：
1. 胃肠道反应：恶心、呕吐、腹痛、腹泻（红霉素最明显，阿奇霉素最轻）

药物名称：氨基糖苷类抗生素通用安全信息
药物分类：氨基糖苷类抗生素
主要不良反应：
1. 肾毒性：近端肾小管损伤，表现为蛋白尿、管型尿、血肌酐升高（可逆）

1. 对氨基糖苷类过敏者禁用
2. 重症肌无力患者禁用
3. 帕金森病患者慎用
4. 妊娠期禁用（可致胎儿耳毒性）
5. 肾功能不全者需调整剂量并监测血药浓度
6. 与袢利尿剂（呋塞米等）合用增加耳毒性
7. 与神经肌肉阻滞剂合用增加呼吸抑制风险
特殊人群提醒：
1. 老年人：肾毒性和耳毒性风险增加，需监测血药浓度
2. 儿童：需监测血药浓度，疗程尽量缩短
3. 孕妇：妊娠期禁用
4. 肾功能不全者：需调整剂量并监测血药浓度
5. 长期使用者：需监测听力和肾功能

药物名称：四环素类抗生素通用安全信息
药物分类：四环素类抗生素
主要不良反应：
1. 牙齿和骨骼：儿童牙齿永久性变色（黄褐色）、骨骼发育抑制
2. 胃肠道：恶心、呕吐、腹泻、食管溃疡
3. 光毒性：皮肤光敏反应（多西环素最常见）
4. 肝毒性：大剂量静脉使用可致肝脂肪变性
5. 肾毒性：过期四环素可致Fanconi综合征
6. 前庭反应：头晕、眩晕（米诺环素）
7. 颅内压增高：良性颅内压增高（假性脑瘤）
8. 二重感染：长期使用致真菌或耐药菌过度生长
用药禁忌：
1. 对四环素类过敏者禁用
2. 8岁以下儿童禁用（牙齿变色和骨骼发育抑制）
3. 妊娠期和哺乳期禁用
4. 严重肝功能不全者禁用
5. 与牛奶、钙剂、铁剂、抗酸药等需间隔2-3小时服用
6. 与口服避孕药合用降低避孕效果
特殊人群提醒：
1. 老年人：无需调整剂量，但需注意肝肾功能
2. 儿童：8岁以下禁用
3. 孕妇：妊娠期禁用
4. 哺乳期：禁用
5. 肝功能不全者：禁用
6. 光敏感患者：使用多西环素时需严格防晒

药物名称：抗结核药物通用安全信息
药物分类：抗结核药
主要不良反应：
1. 异烟肼：肝毒性（需监测肝酶）、周围神经炎（需补充维生素B6）
2. 利福平：肝毒性、橙红色体液（无害但需告知患者）、药物相互作用（强效CYP450诱导剂）
3. 吡嗪酰胺：肝毒性、高尿酸血症（关节痛、痛风）

5. 链霉素：耳毒性（前庭和耳蜗损害）、肾毒性

3. 妊娠期慎用链霉素（耳毒性）

5. 痛风患者慎用吡嗪酰胺

1. 老年人：肝毒性和耳毒性风险增加
2. 儿童：按体重计算剂量，乙胺丁醇需监测视力
3. 孕妇：妊娠期可使用（除链霉素外）
4. 肝功能不全者：需监测肝酶，必要时调整方案
5. HIV感染者：注意药物相互作用（利福平与抗逆转录病毒药）

药物名称：抗病毒药物（通用）
药物分类：抗病毒药

5. 肝功能不全者：某些药物需减量或禁用
