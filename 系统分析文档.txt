一、数据库分析
================================================================================

系统使用 SQLite 作为关系型数据库，数据库文件位于 backend/app_data.db。
数据库包含 4 张表：users、diagnosis_records、operation_logs、chat_history。

此外，系统还使用 ChromaDB 作为向量数据库，用于存储知识库文档的向量嵌入，
支持语义检索。

──────────────────────────────────────────────────────────────────────────────
1.5 ChromaDB 向量数据库
──────────────────────────────────────────────────────────────────────────────

ChromaDB 是一个开源向量数据库，系统使用它来存储知识库文档的向量嵌入。
存储位置：backend/chroma_db/

工作流程：
  1. 上传文档（PDF/DOCX/TXT）→ 提取文本
  2. 文本分块（使用 LangChain 的 RecursiveCharacterTextSplitter）
  3. 生成向量嵌入（使用 DashScope 通义千问 text-embedding-v4 模型）
  4. 存入 ChromaDB 集合
  5. 检索时：将用户查询转为向量 → ChromaDB 相似度搜索 → 返回最相关文档片段

二、系统架构概览
================================================================================

系统采用前后端分离架构，整体分为三层：

┌─────────────────────────────────────────────────────────────────────────────┐
│                           前端层 (Frontend)                                 │
│  Vue 3 + Vite + Element Plus + Vue Router + Pinia + ECharts + Axios        │
│  运行端口：5173（开发）                                                     │
│  目录：frontend/                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                           后端层 (Backend)                                  │
│  FastAPI + Uvicorn + SQLite + python-jose（JWT）                            │
│  运行端口：8000                                                             │
│  目录：backend/                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                         RAG 引擎层 (RAG Engine)                             │
│  LangChain + ChromaDB + DashScope（通义千问）                               │
│  目录：backend/app/rag/（原 RagProject/）                                   │
└─────────────────────────────────────────────────────────────────────────────┘

通信方式：
  - 前端通过 Axios HTTP 客户端调用后端 REST API
  - 后端 FastAPI 通过 CORS 中间件允许跨域请求
  - 认证使用 JWT Token，前端存储在 localStorage，通过 Axios 拦截器自动注入
  - 后端通过 LangChain 框架调用 DashScope（阿里云通义千问）大模型 API

──────────────────────────────────────────────────────────────────────────────
3.2 路由与导航守卫
──────────────────────────────────────────────────────────────────────────────

路由配置（frontend/src/router/index.js）：
  - /login          → Login.vue（公开，无需认证）
  - /               → Layout.vue（需认证，嵌套子路由）
    - /dashboard    → Dashboard.vue（首页）
    - /chat         → Chat.vue（智能问答）
    - /diagnosis-assist → DiagnosisAssist.vue（鉴别诊断）
    - /drug-safety  → DrugSafety.vue（用药安全）
    - /diagnosis-records → DiagnosisRecords.vue（诊断记录）
    - /knowledge-base    → KnowledgeBase.vue（知识库）
    - /logs         → Logs.vue（操作日志）

导航守卫逻辑：
  - 检查 localStorage 中是否存在 token
  - 如果访问非 /login 页面且无 token，重定向到 /login
  - 如果已登录用户访问 /login，重定向到 /dashboard

──────────────────────────────────────────────────────────────────────────────
3.3 状态管理（Pinia）
──────────────────────────────────────────────────────────────────────────────

stores/user.js：
  - state: token, workId, isLoggedIn
  - actions: login(), logout(), checkLogin()
  - 登录成功后保存 token 和 workId 到 localStorage
  - 退出登录时清除 localStorage 并跳转到登录页

──────────────────────────────────────────────────────────────────────────────
3.4 API 通信层
──────────────────────────────────────────────────────────────────────────────

request.js（Axios 实例配置）：
  - baseURL: 'http://localhost:8000'
  - 请求拦截器：自动从 localStorage 读取 token，添加到 Authorization 头
  - 响应拦截器：401 状态码自动触发登出并跳转登录页

index.js（API 接口封装）：
  - authApi：      login(), register()
  - dashboardApi： getStats()
  - diagnosisApi： getRecords(), getRecord(), createRecord(), updateRecord(),
                   deleteRecord(), syncToKnowledgeBase()
  - kbApi：        getDocuments(), uploadFile(), deleteDocument()
  - chatApi：      sendMessage()
  - diagnosisAssistApi： generateDifferentialDiagnosis()
  - drugSafetyApi： checkDrugSafety()
  - logApi：       getLogs(), getLogStats(), getActionTypes()

3.5 各视图功能详解
──────────────────────────────────────────────────────────────────────────────

3.5.1 Login.vue（登录页）
  - 功能：用户登录和注册
  - 组件：el-form + el-input + el-button
  - 交互：输入工号和密码，调用 authApi.login() 或 authApi.register()
  - 样式：渐变背景 + 背景图片覆盖，居中卡片式登录框

3.5.2 Layout.vue（主布局）
  - 功能：系统主框架，包含侧边栏导航和顶部栏
  - 组件：el-container + el-aside + el-header + el-main
  - 侧边栏：el-menu 可折叠导航菜单
  - 顶部栏：显示系统标题、当前用户工号、退出按钮

3.5.3 Dashboard.vue（首页仪表盘）
  - 功能：系统数据总览，展示关键指标
  - 组件：el-row + el-col + el-card + ECharts
  - 展示内容：
    * 指标卡片：用户数、诊断记录数、知识库文档数、对话次数
    * 诊断趋势折线图（近7天每日诊断数量）
    * 疾病分布饼图（各疾病占比）
    * 知识库文件分布饼图（各来源文档占比）
  - 数据来源：dashboardApi.getStats()

3.5.4 Chat.vue（智能临床问答）
  - 功能：与 AI 助手进行临床相关对话
  - 组件：聊天消息列表 + 输入框 + 发送按钮
  - 交互：用户输入问题 → 调用 chatApi.sendMessage() → 流式显示 AI 回复
  - 支持多轮对话上下文

3.5.5 DiagnosisAssist.vue（鉴别诊断）
  - 功能：根据患者症状生成鉴别诊断建议
  - 组件：el-form（症状输入）+ 结果显示区
  - 交互：输入患者症状等信息 → 调用 diagnosisAssistApi.generateDifferentialDiagnosis()
  - 结果：显示可能的诊断列表及依据

3.5.6 DrugSafety.vue（用药安全核查）
  - 功能：检查药物安全性，评估用药风险
  - 组件：el-form（药物名称、年龄、过敏史等）+ 结果显示区
  - 交互：输入药物信息 → 调用 drugSafetyApi.checkDrugSafety()
  - 结果：显示药物安全评估信息

3.5.7 DiagnosisRecords.vue（诊断记录管理）
  - 功能：诊断记录的增删改查
  - 组件：el-table + el-dialog + el-form + el-pagination
  - 功能点：
    * 列表展示所有诊断记录（分页）
    * 搜索过滤（按患者姓名/症状等关键词）
    * 新增诊断记录（弹窗表单）
    * 编辑诊断记录
    * 查看详情
    * 删除记录
    * 同步到知识库（将诊断记录转为知识库文档）

3.5.8 KnowledgeBase.vue（知识库管理）
  - 功能：管理 RAG 知识库文档
  - 组件：el-upload + el-table + el-button
  - 功能点：
    * 上传文档（支持 PDF、DOCX、TXT 格式）
    * 查看已上传文档列表（文件名、片段数、上传时间）
    * 删除文档

3.5.9 Logs.vue（操作日志）
  - 功能：查看系统操作日志
  - 组件：el-table + el-pagination + el-select（筛选）
  - 功能点：
    * 分页展示操作日志
    * 按操作类型筛选
    * 按关键词搜索
    * 显示操作统计

4.2 核心配置模块（core/config.py）
──────────────────────────────────────────────────────────────────────────────

主要配置项：
  - BACKEND_DIR: 后端根目录（自动检测）
  - SECRET_KEY: JWT 签名密钥
  - ALGORITHM: JWT 算法（HS256）
  - ACCESS_TOKEN_EXPIRE_MINUTES: Token 过期时间（默认 480 分钟）
  - CORS_ORIGINS: 允许跨域来源（默认 http://localhost:5173）
  - DATABASE_PATH: SQLite 数据库文件路径
  - CHROMA_PERSIST_DIR: ChromaDB 持久化目录

4.3 数据库模块（core/database.py）
──────────────────────────────────────────────────────────────────────────────

  - get_connection(): 获取 SQLite 数据库连接（返回带 row_factory 的连接）
  - init_database(): 初始化数据库，创建所有表（如果不存在）

──────────────────────────────────────────────────────────────────────────────
4.4 安全模块（core/security.py）
──────────────────────────────────────────────────────────────────────────────

核心函数：
  - create_access_token(data: dict) -> str: 创建 JWT Token
    * 接收 payload 数据字典
    * 添加过期时间（exp）
    * 使用 HS256 算法和 SECRET_KEY 签名
  - verify_token(token: str) -> dict | None: 验证 JWT Token
    * 解码并验证签名
    * 检查是否过期
    * 返回 payload 或 None

──────────────────────────────────────────────────────────────────────────────
4.6 API 路由模块（api/）
──────────────────────────────────────────────────────────────────────────────

所有 API 路由均挂载在 /api 前缀下。

4.6.1 auth.py — 认证路由
  POST /api/login     → 用户登录，返回 JWT Token
  POST /api/register  → 用户注册

4.6.2 dashboard.py — 仪表盘路由
  GET  /api/dashboard/stats → 获取仪表盘统计数据

4.6.3 diagnosis.py — 诊断记录路由
  GET    /api/diagnosis/records              → 获取诊断记录列表（支持搜索）
  GET    /api/diagnosis/records/{id}         → 获取单条诊断记录
  POST   /api/diagnosis/records              → 新增诊断记录
  PUT    /api/diagnosis/records/{id}         → 更新诊断记录
  DELETE /api/diagnosis/records/{id}         → 删除诊断记录
  POST   /api/diagnosis/records/{id}/sync-kb → 同步到知识库

4.6.4 chat.py — 智能问答路由
  POST /api/chat/qa → 智能临床问答

================================================================================
七、认证与安全机制
================================================================================

──────────────────────────────────────────────────────────────────────────────
7.1 JWT 认证流程
──────────────────────────────────────────────────────────────────────────────

  1. 用户输入工号和密码，调用 POST /api/login
  2. 后端验证凭据，生成 JWT Token（包含 work_id 和过期时间）
  3. 前端将 Token 存储在 localStorage
  4. 后续请求通过 Axios 拦截器自动在请求头添加 Authorization: Bearer <token>
  5. 后端通过依赖注入（Depends）验证 Token 有效性
  6. Token 过期后返回 401，前端自动跳转到登录页

──────────────────────────────────────────────────────────────────────────────
7.2 安全特性
──────────────────────────────────────────────────────────────────────────────

  - 密码当前为明文存储（未做哈希加密），这是已知的改进空间
  - JWT Token 有过期机制（默认 8 小时）
  - 前端路由守卫防止未授权访问
  - CORS 中间件限制跨域来源
  - 操作日志记录所有关键操作，便于审计

八、数据流分析
================================================================================

──────────────────────────────────────────────────────────────────────────────
8.1 用户登录数据流
──────────────────────────────────────────────────────────────────────────────

  Login.vue → authApi.login() → POST /api/login → auth_service.login()
  → database.get_connection() → users 表验证 → security.create_access_token()
  → 返回 JWT Token → 前端存储到 localStorage → 跳转到 /dashboard

──────────────────────────────────────────────────────────────────────────────
8.2 智能问答数据流
──────────────────────────────────────────────────────────────────────────────

  Chat.vue → chatApi.sendMessage() → POST /api/chat/qa
  → rag_service.chat()
    → 1. 获取对话历史（file_history_store）
    → 2. 查询向量化（text-embedding-v4）
    → 3. ChromaDB 相似度搜索
    → 4. 构建 Prompt（系统提示 + 检索结果 + 历史）
    → 5. 调用 LLM（qwen3-max）
    → 6. 保存对话历史
  → 返回 AI 回复 → 前端显示

──────────────────────────────────────────────────────────────────────────────
8.3 知识库上传数据流
──────────────────────────────────────────────────────────────────────────────

  KnowledgeBase.vue → kbApi.uploadFile() → POST /api/knowledge-base/upload
  → kb_service.upload_by_str()
    → 1. 提取文本（PDF/DOCX/TXT）
    → 2. 计算 MD5，检查是否已上传
    → 3. 文本分块（RecursiveCharacterTextSplitter）
    → 4. 生成向量嵌入（text-embedding-v4）
    → 5. 存入 ChromaDB
  → 返回上传结果 → 前端刷新文档列表

──────────────────────────────────────────────────────────────────────────────
8.4 诊断记录同步到知识库数据流
──────────────────────────────────────────────────────────────────────────────

  DiagnosisRecords.vue → diagnosisApi.syncToKnowledgeBase()
  → POST /api/diagnosis/records/{id}/sync-kb
  → diagnosis_service.format_record_for_knowledge_base()
  → kb_service.upload_by_str()（将格式化文本上传到知识库）
  → 返回同步结果
